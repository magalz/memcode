# The MemCode visual standard

The Memtrace benchmark page is the reference for material, restraint and clarity.
Translate its principles into a working desktop application rather than reproduce
a marketing page or the previous orchestrator board.

| Token | Value     | Purpose                                |
| ----- | --------- | -------------------------------------- |
| Ink   | `#07110e` | Strong readable hierarchy              |
| Paper | `#f3f7f4` | Quiet workspace surfaces               |
| White | `#fbfdfb` | Content and cards                      |
| Mint  | `#18c8b5` | Focus, progress and purposeful accents |
| Cyan  | `#6edff5` | Secondary intelligence accent          |
| Muted | `#66706c` | Supporting copy                        |

Self-host Inter Variable. Keep body text readable at normal desktop scale. Use a
small mono label for identifiers, not for paragraphs. Prefer a consistent spacing
scale, fine borders, soft shadows and a few deliberate contrasts.

The board and list carry the same hierarchy: identifier, outcome, context, runbook
progress, worker. Status should help scanning without turning the workspace into a
wall of colored badges. Detail views keep the conversation primary and evidence
close. Browser content lives in an isolated native WebView with no app RPC capability.

Motion should explain state, finish quickly and honor reduced-motion preferences.
Every visible control needs a meaningful action, disabled explanation, or empty
state. Preview data must remain labelled. Never animate a fictional live worker.

Visual verification includes board, list, detail, runbook, new project, new work,
artifacts, native preview, search, settings and at least two desktop widths.
